What agents add

Coordinated execution, contextual summaries, failure diagnosis, evidence assembly and run-level traceability—without duplicating the established modelling/validation implementation.

Non-negotiable model-risk rule

Agents can recommend. They cannot silently change target definitions, validation thresholds, model inventory status, production configuration or release decisions.

Low-Level Design

Concrete service boundaries, state contract, graph routing, execution semantics, idempotency and failure handling.

Workflow Command API

Validate identity/config, normalize payload, derive request hash, enforce idempotency, persist run metadata and return run_id.

LangGraph Orchestrator

Typed state, graph nodes, conditional edges, checkpoint persistence, bounded retry and resumable execution.

Agent nodes

Each node receives minimal state, calls one allow-listed service, validates structured output and emits artifact references.

Tool adapter

Allow-listed pipeline invocation, timeout, output capture, process exit validation and artifact manifest.

Artifact / Evidence service

Registers path, SHA-256, run ID, model version, dataset fingerprint and report lineage.

Approval service

Decision, reviewer, timestamp, reason and expected artifact hash bind sign-off to exact evidence.

Runtime algorithms

Run acceptance

1 Authenticate caller / validate role 2 Validate workflow schema and parameters 3 Normalize request; compute request_hash 4 Check Idempotency-Key + prior request_hash 5 Create run record (QUEUED) and event 6 Persist dataset/model configuration snapshot 7 Return 202 {run_id, status, status_url}

LangGraph node execution

1 Load checkpointed CreditRiskState 2 Verify run not cancelled / budget available 3 Validate node preconditions 4 Invoke allow-listed service or pipeline 5 Validate output schema and exit status 6 Register artifact + checksum + lineage 7 Update stage, append event, checkpoint 8 Route success / retry / failure / approval

Model promotion gate

1 Read validation report and artifact hashes 2 Evaluate required evidence / threshold policy 3 Set recommendation: PROMOTE / HOLD / REJECT 4 Persist recommendation (not approval) 5 Pause at interrupt/checkpoint 6 Reviewer decision with identity + reason 7 Verify approved hash matches candidate 8 Only then update inventory / deployment workflow

Failure and recovery

1 Classify error: validation / transient / terminal 2 Retry transient failure with bounded backoff 3 Never retry non-idempotent action blindly 4 Preserve logs, traceback summary and run context 5 Checkpoint last successful stage 6 Resume from checkpoint or create linked rerun 7 Terminal status + alert + evidence package

LangGraph state machine

State / stageTransitionRule
QUEUED→ RUNNING / CANCELLEDRequest validated and accepted.
DATA_INTAKE→ PREPARATION / FAILEDSchema, target, row count, fingerprint pass.
PREPARATION→ TRAINING / FAILEDFeature contract and split policy pass.
TRAINING→ VALIDATION / FAILEDArtifacts and metadata registered.
VALIDATION→ GOVERNANCE / HOLDMetrics/report available; policy evaluated.
GOVERNANCE→ APPROVAL_PENDING / REJECTEDEvidence complete; reviewer is authoritative.
APPROVAL_PENDING→ APPROVED / REJECTED / EXPIREDApproval binds candidate artifact hash.
API_QA → MONITORING→ SUCCEEDED / FAILEDDeployment is a separate controlled action.

Failure, retry and compensation

FailureLLD behavior
Invalid dataset / schemaFail fast; no model training.
Transient I/O / service errorBounded exponential backoff with jitter.
Training process nonzero exitCapture safe logs; mark stage failed; preserve prior artifacts.
Validation threshold breachRoute HOLD; no promotion request auto-approved.
Worker restartResume from checkpoint if node is safe/idempotent.
Duplicate run requestIdempotency returns original run; hash mismatch returns conflict.
Artifact mismatch at approvalInvalidate approval; require fresh review.

Security, observability and readiness

Authorization

Role-scoped workflow creation, status access, cancellation and reviewer-only approval.

Data protection

Do not log raw customer rows, credentials or feature values; use synthetic data for demo runs.

Secrets

Environment/secret manager; no secrets in graph state, prompts or event payloads.

Tracing

Correlation ID through API, graph nodes, subprocesses and artifacts; sanitized structured logs.

Alerts

Queue age, stuck stage, repeated failures, validation deterioration, drift and approval backlog.

Go-live

Idempotency, retry, cancellation, crash/restart, permissions, audit and artifact retention tested.

Key risks and mitigating controls

RiskMitigation
Duplicated ML logicAgents call existing pipeline entrypoints; no reimplementation.
Concurrent training overloadWorker queue, per-run workspaces, CPU/memory/concurrency budgets.
Agent claims success without outputsVerify exit code, expected artifacts and hashes before stage completion.
Automatic model promotionDurable approval gate; model inventory remains authoritative.
Checkpoint lossPersistent LangGraph checkpointer and recovery test.
Data leakage / privacyInput minimization, safe logs, RBAC, synthetic demo and lineage.
Agent loop / cost growthMax nodes, wall time, retries, token budget and explicit terminal route.
